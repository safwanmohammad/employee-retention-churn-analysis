# Methodology

The project follows an end-to-end data analytics workflow from raw data preparation to business insights.

---

# 1. Data Collection

The project uses three datasets representing:

- Job listings
- Recruitment KPIs
- Employee retention KPIs

These datasets contain job market, recruitment, and employee turnover information.

---

# 2. Data Cleaning Using Python

Python was used to prepare the data before analysis.

### Cleaning activities included:

- Loading datasets using Pandas
- Inspecting data types
- Checking missing values
- Checking duplicate records
- Validating categorical values
- Reviewing numerical fields
- Formatting date fields
- Creating analytical categories
- Preparing datasets for database analysis
